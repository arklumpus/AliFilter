# Manuscript figures

This folder contains the scripts and data used to create the figures in the AliFilter manuscript.

Note that some large files (bootstrap replicates for the simulated dataset) are stored using Git LFS and are not downloaded by default when fetching the repository. To download them, you can use the following command:

```bash
git lfs pull -I "Figures/Figure_S11/Data/Trees/*.ufboot"
```
